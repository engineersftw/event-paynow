# Architecture

## Overview

A single Cloudflare Worker (`event-paynow`) that exposes a Telegram webhook endpoint, generates SGQR PayNow QR codes, and persists payment records.

## Components

```
┌──────────────────────────────────────────────────────────┐
│                     Cloudflare Worker                     │
│                                                          │
│  fetch() handler                                         │
│  ├── GET /              → health check                   │
│  └── POST /webhook      → grammY webhook (secret-token   │
│                           validated)                     │
│                                                          │
│  grammY Bot                                              │
│  ├── /init            → /payee-configuration             │
│  ├── /start           → /payment-qr-issuance             │
│  ├── /payments        → /payment-tracking                │
│  ├── /payback <ref>   → /payback-qr                      │
│  └── /cancel          → abort current conversation       │
│                                                          │
│  ┌─────────────────────┐   ┌──────────────────────────┐ │
│  │ ChatSessionDO       │   │ SGQR payload builder     │ │
│  │ (per-chat state)    │   │ (runtime-agnostic)       │ │
│  │ - conversation FSM  │   │ - TLV encoder            │ │
│  │ - 10-min alarm      │   │ - CRC16-CCITT checksum   │ │
│  │ - zod state schema  │   │ - PNG renderer           │ │
│  └─────────────────────┘   └──────────────────────────┘ │
│                                                          │
│  ┌──────────────────────────────────────────────────────┐│
│  │ Repository layer (Drizzle ORM over D1 binding)       ││
│  │ users │ payments │ paybacks                          ││
│  └──────────────────────────────────────────────────────┘│
└──────────────────────────────────────────────────────────┘
            │                              │
            ▼                              ▼
    ┌──────────────┐              ┌──────────────┐
    │   D1 DB      │              │ Durable      │
    │ (paynow-db)  │              │ Object store │
    │              │              │ (per-chat)   │
    └──────────────┘              └──────────────┘
```

## Storage

| Component | Storage | Role |
|---|---|---|
| D1 `paynow-db` | Serverless SQLite | Users, payments, paybacks — durable records |
| Durable Object `ChatSessionDO` | DO Storage (per-instance) | Conversation FSM state per chat, with 10-min alarm expiry |

## Key files

| Path | Role |
|---|---|
| `src/worker.ts` | Fetch handler (routing) |
| `src/bot.ts` | grammY bot factory, secret validation, webhook handler |
| `src/index.ts` | Worker entry (default export) + ChatSessionDO export |
| `src/sgqr/` | SGQR payload builder (TLV + CRC16) + QR PNG renderer |
| `src/db/schema.ts` | Drizzle table definitions |
| `src/db/repository.ts` | Repository layer (Drizzle queries, infra-neutral interfaces) |
| `src/payments/service.ts` | Business logic: markPaymentReceived, payback bounds |
| `drizzle/` | SQL migrations (generated by `drizzle-kit generate`) |
| `wrangler.toml` | Worker config: D1 binding, DO binding, secrets |
| `test/node/` | Node-pool vitest tests (runtime-agnostic core) |
| `test/workers/` | Workers-pool vitest tests (D1, DO, integration) |

## Deploy commands

```bash
# Initial setup
npm install
wrangler d1 create paynow-db        # capture the database_id
# Update database_id in wrangler.toml
wrangler d1 migrations apply paynow-db
wrangler secret put TELEGRAM_BOT_TOKEN
# Set commands in BotFather: /init /start /payments /payback /cancel
# Register webhook (after deploy):
curl "https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://event-paynow.<worker>.workers.dev/webhook&secret_token=<TOKEN>"

# Deploy
npm run deploy      # wrangler deploy

# Rollback
wrangler versions rollback
```
