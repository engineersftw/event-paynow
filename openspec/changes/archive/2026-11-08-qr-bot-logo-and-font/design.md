# Design

## Context

`renderQrPng(payload, lines)` in `src/sgqr/qr-render.ts` builds a 24-bit BMP by hand (8 px per module, 2-module margin). The centre uses a 1-bit single-colour mask of the PayNow wordmark (`paynow-logo.ts`, 128x79, generated by `scripts/generate-paynow-logo.mjs`). The text band uses a 5x7 bitmap font at 2x (`font5x7.ts`), 20px rows, truncating with `...`. The renderer must stay pure JS with no canvas or Node APIs, because it runs in the Worker; Node tests wrap it and decode with jsQR. The bot logo is `web/public/logo.png` (128px, transparent, cropped), made from the user's image.

## Goals / Non-Goals

**Goals:** bot logo (full colour, smooth edge) in the centre; smooth proportional text; QR still scans; no runtime dependency, no change to payloads.

**Non-Goals:** non-ASCII text on the image (still drawn as `?`; Latin-1 could follow), bold or multiple fonts, changing QR size or error-correction level, a general image library.

## Decisions

1. **Logo as embedded RGBA.** A script (`scripts/generate-bot-logo.mjs`, using `pngjs` already in devDependencies) reads the logo PNG, area-averages it to 96x96 and writes `src/sgqr/bot-logo.ts` exporting width, height and a base64 string of raw RGBA (about 49 KB). It is decoded once at module load with `atob`. Alternatives: the single-colour mask no longer fits a multi-colour icon; a deflated blob would add a decode step for a saving that does not matter here.
2. **Compositing.** For each pixel in the logo box, bilinearly sample the RGBA and alpha-blend over white, which gives smooth edges. The logo box is square: width about 22% of the module count (was 24% for a wide logo), with 1 module of white padding, so the covered area is under 8% of the code, well inside level H's 30%. The size is confirmed by jsQR round-trips over several payload lengths and, if a case fails, shrunk before anything else.
3. **Font as a pre-rendered anti-aliased atlas.** A Python script (`scripts/generate-font.py`, Pillow with FreeType) renders printable ASCII (0x20 to 0x7E) of **DejaVu Sans** (a permissive licence, available on most systems) at a fixed pixel size chosen by eye in 20 to 24 px, and writes `src/sgqr/font-atlas.ts` with, per glyph, advance, bitmap size, offsets and 8-bit coverage rows packed into one base64 string (about 25 KB). Alternatives: embedding vector outlines needs a rasteriser in the Worker; a Node-only generator would need a new dependency such as opentype.js. Trade-off: one more script in another language, run rarely; the committed module is the source of truth.
4. **Text drawing.** The band keeps one line per row. Row height follows the font's line height. A line is laid out by summing advances, truncated with an ellipsis by measured width (not character count), drawn by blending glyph coverage as `255 - coverage` black on white. Characters not in the atlas map to `?` as before. The 5x7 font, its tests and the character-count truncation are removed.
5. **Delete what becomes unused.** `paynow-logo.ts`, `font5x7.ts` and `generate-paynow-logo.mjs` go away; README and AGENTS references are updated (design decision 2 in `AGENTS.md` describes the old font and logo).
6. **Performance.** Text blending and bilinear sampling add work per pixel only inside the logo box and the text band. The existing render-time test (500 ms ceiling) must still pass; if it does not, sample the logo once per box pixel into a small cache.

## Risks / Trade-offs

- A busy full-colour icon in the centre is harder for scanners than the flat wordmark. Mitigation: white clear box, level H, jsQR checks at several lengths; also check with a real phone scan before shipping.
- The logo is copyrighted artwork supplied by the user; DejaVu's licence permits embedding glyph renderings. No third-party attribution is required for DejaVu beyond keeping its licence available; the generator script's header notes the source font.
- The bundle grows by about 75 KB (logo plus atlas), small against Worker limits.
- Fixed font size means very long lines are shortened sooner than with the 5x7 font on narrow QR images.
