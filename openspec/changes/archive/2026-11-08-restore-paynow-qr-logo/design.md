# Design

## Context

PR #34 swapped the centre overlay from a 1-bit PayNow mask (`paynow-logo.ts`, 128x79, single colour `rgb(148, 28, 128)`, generated by `scripts/generate-paynow-logo.mjs`) to a full-colour bot logo (`bot-logo.ts`, 96x96 premultiplied RGBA, bilinear blend) and, in the same change, replaced the 5x7 font with the DejaVu atlas. Only the logo is being reversed. The previous renderer code is in git history at `eb680e2^`.

## Goals / Non-Goals

**Goals:** the centre shows the PayNow logo as it did before #34; keep the smooth text; QR still scans.

**Non-Goals:** touching the text rendering, the web admin logo, payloads or captions; a runtime switch between logos.

## Decisions

1. **Restore from history, not re-derive.** `git checkout eb680e2^ -- src/sgqr/paynow-logo.ts scripts/generate-paynow-logo.mjs` brings back the exact mask and its generator. The generator needs the PayNow brand PNG, which is not in the repo; the committed mask is the source of truth, as before.
2. **Put the old overlay code back.** In `qr-render.ts`: an aspect-preserving box (24% of the modules wide), 1 module white padding, 1-bit mask sampling with the brand colour, and delete `sampleLogo`. The text band code from #34 stays untouched. A revert of just those hunks, not of the whole PR.
3. **Remove what becomes unused.** `bot-logo.ts` and `generate-bot-logo.mjs` have no other consumer (the web page uses `web/public/logo.png` directly), so they are deleted rather than kept for later.
4. **Tests.** Restore the old colour check in `qr-logo.test.ts` using `LOGO_COLOR`; keep the added short/medium/long payload decode test and the text tests unchanged.
5. **Deploy.** `src/sgqr/` is now in the Pages filter, so one merge redeploys the Worker and Pages together.

## Risks / Trade-offs

- A third logo change in a short time; each change is a small, reversible edit.
- The restored mask is single colour at 128x79; this is the pre-#34 look, which was accepted before.
